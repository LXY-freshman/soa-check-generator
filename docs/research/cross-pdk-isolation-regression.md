# 跨工艺隔离结解析回归

2026-11-09，只读选取用户已提供的六套已解压工艺目录中的 Spectre 模型与可见原生 SOA 文件。未解压工艺不在范围内，未调用 Virtuoso 或 Spectre。源文件仅进入进程内存，Git 中仅包含下面的汇总与自建脱敏样例。

物理依据见 [隔离结构研究](isolation-junction-principles.md)。从实际 diode 模型/明确的两端子 diode 包装子电路追踪 P/N 极性，跨文件只关联用户明确选中的文件。方向为反向 `V(N,P)` 和正向 `V(P,N)`。结构已识别不表示耐压已知，阈值、温度、持续时间和正向电流均须独立取证。

上述范围是本轮所选文件；数字不是工艺全器件或全物理机制覆盖率。正向矩阵多数保留空值等待用户填写；仅结构图完整时生成有确定方向的正向模板，不预置统一 VF。别名与参数化变体仍各自保留。

DB HiTek 的七端 PMOS 模型明确有 `ISUB-B`、`ISUB-ISO`、`SUB-ISO` 三条二极管连接，生成三组反向/正向检查，不把 ISO 与 B 直接连成一条虚构 PN 结。UNT 的七端 PMOS 同样明确有 `PEPI-B`、`PEPI-NBL`、`PSUB-NBL` 三条连接。SMIC 的寄生模型声明在单独文件时，选中该文件后可与 MIS/HV MOS 端口关联。

无结构证据时只保留可复核的隔离关系候选，不给正向方向或数值。外侧 PSUB 未暴露或未确认时，矩阵显示覆盖缺口，不创建引用不存在端口的可导出表达式。介质隔离不套用衬底 PN 模板。同电位要求及复合寄生路径可通过带来源的 `isolation_constraint` 手工/适配器规则表达，不能自动声称已经覆盖闩锁或布局失效。

回归验证包含：单文件/多文件/网页文本四种解析入口、跨文件顺序无关、原生正向/反向规则分别匹配、内外数值不相互复制、默认关闭、项目 round trip、CLI、适配器验证、网页独立编辑和 520px 窄窗口。
