# 隔离结构与 SOA 检查的物理依据

调查时间：2026-11-09。依据用户提供的已解压原厂设计手册、官方技术资料及实际模型端口调查。原始 PDK 只读，不复制手册、模型或凭据到 Git，不处理压缩包，不调用 Virtuoso/Spectre。

## 结论

隔离检查应建模为“结构中的结或约束”，不能建模为所有带 `iso` 字样端口之间的全连接。至少区分反向耐压、正向偏置/注入、复合寄生路径限制和要求同电位的结构约束。工艺名、器件族、端口名可以帮助提出候选，但不能独自证明任意两个端口构成独立 PN 结。

对已经确认 P/N 极性且相邻的结：反向电压使用 `V(N,P)`；正向偏置使用 `V(P,N)`。两种检查的阈值、持续时间、温度条件和允许电流应分别从原生 SOA、模型或手册绑定。不能把反向耐压写成对称的 `±BV` 来替代正向检查；也不能把某个常用二极管压降当所有工艺的正向导通阈值。这个符号约定是依据 PN 结两侧电势定义作出的实现推导，使用时仍须核对具体模型的引脚定义。

手册定位使用文件名、章节和 PDF 页码，避免在研究记录中复刻受限资料。以下是事实的转述，不是可跨工艺复用的数值规则。

| 原始资料 | 定位 | 支持的事实及实现含义 |
|---|---|---|

| 同上 | PDF 第 19–20 页，§6.2.1，寄生模型与 flag 说明 | NBL pocket 的内外区域形成寄生二极管与 PEPI–NBL–PSUB 寄生 PNP；内外端口有各自连接。部分寄生模型默认开关不同，且手册指出并非所有内部寄生路径都被模型覆盖。仅检测到 `gsoa` 或寄生模型存在不能宣称所有检查齐全。 |
| 同上 | PDF 第 25 页，§6.2.1.d，pocket characterization | 内侧 PEPI–NBL、外侧 NBL–PSUB、以及 PEPI–PSUB 复合寄生路径的限制不同。表中的 DC breakdown、TLP breakdown、工作电压和温度依赖不是同一种限值，不能合成一个阈值。 |

| `TD-BC18-DM-2004v2.pdf` | PDF 第 51–54 页；印刷页 48–51，§7.2.1.9 | BCDE 的普通/fully isolated NMOS、PMOS 结构并不相同。某个 PMOS pocket 变体要求 NW 与 HVBN 等电位；应表达为结构约束，不能给它猜出一个允许独立承压的差压值。 |

## 公开的一手资料

1. TI，Marty Johnson 等，《Latch-Up》，SCAA124，2015，第 2–4 页。说明 CMOS/BiCMOS 内的寄生 PNPN 路径可由电流注入或过压触发；阱/衬底电阻、温度、脉冲条件和寄生晶体管反馈都参与其中。guard ring、substrate ties、well taps、EPI 是降低敏感性的结构措施。来源：[TI 官方 PDF](https://www.ti.com/lit/an/scaa124/scaa124.pdf)。
2. Analog Devices，《Analog Switches and Multiplexers Basics》，MT-088，2008，第 19–22 页。区分结隔离 CMOS 的寄生 SCR 路径与带 trench、buried oxide 的介质隔离结构；后者的完整绝缘边界不形成对应的反偏衬底 PN 结。不同隔离机制不能套用同一组 PN 结模板。来源：[ADI 官方 PDF](https://www.analog.com/media/en/training-seminars/tutorials/MT-088.pdf)。

实现推论：普通大衬底 pickup/guard ring 不等同于可浮置高压隔离岛。`PSUB` 是大衬底节点，不是“隔离层”的证据。静态电压/电流 assert 可以覆盖已经定义的触发条件，但不能声称证明 layout 不闩锁或完全验证寄生瞬态、寄生 BJT 和全芯片注入传播。

## 生成规则应遵守的结构边界

| 关系 | 必要前提 | 应提供的检查/处理 |
|---|---|---|
| NBL/HVBN/DNW 与外侧 PSUB | 明确 N 型隔离层接 P 型大衬底，且两个节点在目标模型可访问 | 独立的反向耐压与正向偏置候选；缺值留空。 |
| N 型隔离层与内部 Pwell/body/PEPI | 截面、模型二极管或工艺配置确认该内部区域为 P 型并构成对应结 | 内侧反向/正向检查，限值不从外侧复制。 |
| PMOS body/Nwell 与 NBL/HVBN | 先确认是否存在 PEPI/Pwell 中间层，或是否须等电位 | 中间层已暴露时检查各实际 PN 结；复合路径或同电位要求独立建模，不生成假直接 PN 结。 |
| DPW 与其他区域 | 先确认 P 型 DPW 邻接哪个 N 型区域 | 依据已证实的 P–N 极性生成；不把任意 body 当 N 侧。 |
| PEPI 与 PSUB | 两者名称本身通常表示 P 型区域 | 不生成“直接 PN 正向/反向结”模板；只有资料明确的 punch-through/寄生 PNP 复合限制才单独生成。 |
| ISO/ISUB 等抽象名称 | 工艺手册或模型拓扑说明节点含义及上下层关系 | 端口并列出现不足以确认极性；保留待确认的结构候选，并允许适配器声明真实关系。 |
| SOI/介质隔离 | 手册确认完整介质隔离边界 | 不自动补不存在的 substrate PN 结。介质绝缘、电场及器件本体限制按独立来源处理。 |
| 无大衬底引脚的模型 | 该节点未暴露为可访问端口 | 标明检查缺少节点证据；不能导出引用不存在 PSUB 的表达式。 |

建议每条关系保留两端名称、P/N 极性或未知状态、内外侧、机制（PN/复合/介质/同电位）、适用性依据及独立限值来源。允许工艺适配器补充不同命名。推断与未知结构默认关闭，用户确认后才进入输出。
