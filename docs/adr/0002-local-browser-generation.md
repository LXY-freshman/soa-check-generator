# Keep generation local in the browser

第一版采用本地浏览器界面加本地 Python 小服务运行，工艺资料和生成内容不上传。小服务负责读取用户选择或手工输入的本机/SSH 路径，浏览器负责解析结果展示、规则编辑、复制和导出；未来二次开发通过稳定的数据格式或本地调用边界扩展，不把核心规则绑定到在线服务。

**Status**: accepted

**Consequences**: 大型 PDK 资料需要分阶段读取或建立本地索引，浏览器端必须清楚显示解析失败、推断值和待确认项；路径输入需要区分本机文件系统和只读 SSH 来源；AI 能力应作为可选的本地调用入口，而不是生成流程的隐式依赖。
